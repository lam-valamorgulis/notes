Call stack & execution context lesson 0001

TermPlain meaningThe detail that matters
Execution context A record of one running call Holds: position in the code (to resume), the call's own variable bindings, the this value. One call = one context; recursion = many contexts of one function.
Call stack The pile those records live on Push on call, pop on return — LIFO. Only the top context runs; all below are paused mid-statement and resume exactly where they stopped.
Blocking Stack busy = page frozen One stack per agent (≈ per tab). While any context is on it: no clicks, no rendering, no other JS.
Stack overflow Too many nested calls RangeError: Maximum call stack size exceeded. Cause: recursion with no exit. Signature: a repeating cycle of names in the trace — the cycle names the fix site. Not an out-of-memory error (that is the heap).
Stack trace A photo of the stack at throw time Read top-down: line 1 threw, every line below is a paused caller. Live version: DevTools → Sources → pause → Call Stack pane; click any frame to inspect that call's still-alive variables.
