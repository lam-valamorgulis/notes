Part C — honest gaps

Things this workspace does not cover in depth. If the interview goes there, the sprint lesson is all you have, and that is worth knowing in advance.

GapRiskWhat to do
Testing React — Testing Library, mocking, integration testsMedium. "How do you test a component?" is a common question and there is no lesson on it anywhere in this repo.Learn one answer well: test behaviour through the DOM the user sees, not implementation. Use getByRole. Mock at the network boundary with MSW, not by mocking your own modules.
TypeScript in depth — generics, utility types, discriminated unionsLow–medium. It is used throughout the lessons but never taught directly.React L26 has the best worked example: a discriminated-union state with an exhaustiveness check.
HTML5 & CSS3 fundamentalsLow. Sprint L15 covers the interview surface, but there is no deeper lesson.If you have spare time, web.dev · Learn CSS is the fastest complete source.
Accessibility beyond the basicsLow for this role, rising every year.The four cheap wins in L15 cover an interview. Real depth is a later project.
React Router in depthLow. It appears in Kata 3 only as useSearchParams.Know route-based code splitting and why filters belong in the URL. That is usually enough.
