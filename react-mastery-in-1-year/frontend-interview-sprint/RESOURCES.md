# 7-Day React Interview Sprint — Resources

## Knowledge

- [React docs — Learn React](https://react.dev/learn)
  The official, rewritten-in-2023 tutorial. Use for: any "how does React
  actually work" answer. Interviewers quote this; so should you.
- [React docs — "You Might Not Need an Effect"](https://react.dev/learn/you-might-not-need-an-effect)
  The single highest-value page for a senior interview. Use for: any question
  about `useEffect`, derived state, or "why is my component re-rendering".
- [Redux Toolkit — Why Redux Toolkit?](https://redux-toolkit.js.org/introduction/why-rtk-is-redux-today)
  Use for: the "why Redux" answer. RTK *is* Redux now; saying "Redux is too
  much boilerplate" marks you as five years out of date.
- [Redux Essentials tutorial](https://redux.js.org/tutorials/essentials/part-1-overview-concepts)
  Use for: the data-flow diagram you will draw on the whiteboard.
- [Zustand docs](https://zustand.docs.pmnd.rs/getting-started/introduction)
  Use for: the "when would you pick Zustand over Redux" comparison.
- [TanStack Query — Overview](https://tanstack.com/query/latest/docs/framework/react/overview)
  Use for: the server-state vs client-state distinction. This one idea makes
  you sound senior faster than anything else on this list.
- [MDN — Media Capture and Streams API](https://developer.mozilla.org/en-US/docs/Web/API/Media_Capture_and_Streams_API)
  Use for: the WebRTC / `getUserMedia` follow-up questions.
- [web.dev — Learn CSS](https://web.dev/learn/css)
  Use for: flexbox vs grid, responsive, and "how do you do CSS at scale".
- [Vite — Why Vite](https://vite.dev/guide/why.html)
  Use for: the Webpack-vs-Vite answer, with the real reason (native ESM,
  esbuild pre-bundling), not "Vite is faster".
- [Google Engineering Practices — Code Review](https://google.github.io/eng-practices/review/)
  Use for: the code-review questions. It is the most quoted standard there is.

## Wisdom (Communities)

- [r/reactjs](https://www.reddit.com/r/reactjs/) — weekly "who's hiring" and
  interview threads; good for checking what is actually asked in 2026.
- [Reactiflux Discord](https://www.reactiflux.com/) — high-signal help channel.
  Use for: sanity-checking an answer before you say it in an interview.
