# Mission: 7-Day Senior Frontend (React) Interview Sprint

## Why
The goal is not "learn React". The goal is to **walk out of a live technical
interview having explained, out loud, in English, why every choice in my React
code was the right one** — and to have written working React in front of a
stranger without freezing.

## Success looks like
- I can answer any question on the job description's list without hesitating:
  React, ES6+, HTML5, CSS3, Redux / Zustand / Context, REST integration,
  Webpack / Vite, responsive design, Git, code review, agile.
- I can **live-code** a small React feature in 25 minutes while talking.
- I can tell the story of the real-time collaboration product I worked on
  (video calls, chat, presence) as a 90-second STAR answer, and survive three
  levels of follow-up questions about it.
- I can say "I don't know, here is how I'd find out" without losing the room.
- My English holds up under pressure: I have rehearsed sentences, not
  improvised ones.

## Constraints
- **7 days**, ~8 hours a day. Full sprint.
- Interview format: **technical Q&A + live coding in React**.
- English is a second language. Spoken answers must be rehearsed out loud,
  not just read.
- Redux: used before, but cannot explain it well. Needs the *why*, not syntax.
- Real React experience exists but is **rusty** — this is refresh + gap-fill,
  not beginner teaching.

## Out of scope
- Next.js, React Server Components, SSR. Not on the job description.
- Backend, databases, deployment. Other courses cover those.
- Deep algorithms / LeetCode. This is a product frontend role, not FAANG.
- Building a portfolio project from scratch. No time.
