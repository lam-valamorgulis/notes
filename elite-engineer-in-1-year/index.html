The big picture — how it all connects

The year has one shape: go under the browser, rebuild the framework layer yourself, turn that depth into product craft, then take the same standard into AI. Nothing here is a course you watch. Every month you write a real thing from an empty file, put it in front of real people, defend it out loud, and publish what happened.

Months 1–3 go under the browser. You start with what a program is and what a tab really is — a shell with real pipes, then a tool that measures a page's true cost, so "the main thread is blocked" stops being a phrase and becomes a picture. Then the JavaScript engine and the event loop: you write a working programming language, and after that month "JavaScript is weird" is over forever, because you know where a closure keeps its variables. Then the wall — you write a layout engine, with text wrapping, and reflow stops being folklore.

Months 4–6 rebuild the framework layer. You write your own React — fibers, reconciliation with keys, hooks as a linked list, an interruptible scheduler. Then your own bundler, with source maps and hot module replacement, so the build step stops being a magic box you configure. Then an HTTP server on a raw socket that streams HTML, so you can prove why streaming beats buffering instead of quoting someone who did.

Months 7–9 turn depth into product. Month 7 is performance as a discipline — five measured rounds on a real site, field data only, gated in CI. Month 8 is taste, accessibility, and deletion: rebuild one surface to a fanatical standard and finish with less code than you started with. Month 9 is offline, real-time, and browser security, where you write working exploits against your own application before anyone else does.

Months 10–12 are AI, held to the same standard. You build an autograd engine and a small GPT by hand, so models are arithmetic you have typed rather than magic you invoke. Then an agent from raw API calls, a streaming interface you wrote yourself, and evals that block a bad deploy — that combination is the rare one, and it is where your front-end depth pays twice. Finally zero to one, alone, on a deadline: a whole AI product in four weeks, real users, and a defence of every layer from the React render down to the syscall.

Two things never change. Every month needs the same four proofs — built from a blank page, shipped to real users, defended out loud, published in writing. And the daily shape stays the same all year: two protected two-hour build blocks, plus recall, reading, drills, and an honest ledger.

The part that makes this different Every month can be failed, and the failure condition is written down in advance so you cannot quietly move the goalposts. In Months 4, 6, 9, and 12 an outside senior engineer judges you — not me, and not you. You never grade your own exam.

Stage 1 · Months 1–3 · The machine under the browser

Stop guessing about the platform. Learn — and partly rebuild — the machine your React code runs on.

Month 1 · 10 Aug – 6 Sep 2026

What a program is, and what a tab really is os · processes

Processes, virtual memory, syscalls, file descriptors — then Chrome's real shape: browser process, renderer per site, GPU process, main thread versus compositor thread.

Build: a shell with real pipes, then a page-cost CLI on npm.

Month 2 · 7 Sep – 4 Oct 2026

The JavaScript engine and the event loop v8 · gc

Bytecode, hidden classes, deoptimisation, garbage collection, heap snapshots — then tasks, microtasks, frames, and starvation.

Build: a working programming language, plus an event-loop simulator.

Month 3 · 5 Oct – 1 Nov 2026

The rendering pipeline — write a layout engine layout · paint

DOM, cascade, layout, paint, raster, composite. Which stages a change re-runs, and why transform is cheap while top is not.

Build: a mini browser engine that wraps text and paints to a canvas.

Stage 2 · Months 4–6 · The framework layer

Rebuild the tools you use every day. After this stage, no framework is a black box — and no framework question can corner you.

Month 4 · 2 Nov – 29 Nov 2026 · first outside judge

Write a mini React fibers · hooks

Reconciliation with keys, the render and commit phases, hooks as a linked list, and a scheduler that can be interrupted.

Build: your own React, tested against the real one.

Month 5 · 30 Nov – 27 Dec 2026

The build layer bundler · hmr

Module graphs, transforms, tree shaking and what defeats it, code splitting, source maps, hashing, and how hot module replacement really swaps a module.

Build: a bundler with a working source map and HMR, plus a CI size budget.

Month 6 · 28 Dec 2026 – 24 Jan 2027 · second outside judge

The network, from the socket to first paint http · streaming

TCP, TLS, HTTP/1.1 to HTTP/3, caching layers, preload hints — then client rendering versus server rendering, streaming HTML, and the real cost of hydration.

Build: an HTTP server on a raw socket that streams HTML progressively.

Stage 3 · Months 7–9 · The product

Turn the depth into things users feel. Depth with no taste produces clever software nobody wants.

Month 7 · 25 Jan – 21 Feb 2027

Performance as an engineering discipline vitals · inp

Lab versus field, LCP and INP and CLS, long tasks, the frame budget, virtual lists, workers, real-user monitoring, and budgets that fail a pull request.

Ship: two vitals improved in the field, with the CI gate to keep them.

Month 8 · 22 Feb – 21 Mar 2027

Taste, accessibility, and deletion craft · a11y

Every state designed, motion with a purpose, design tokens, WCAG 2.2 and the ARIA patterns, and Ousterhout's rules for the code behind it.

Build: a combobox and a dialog to spec. Delete a third of a real surface.

Month 9 · 22 Mar – 18 Apr 2027 · third outside judge

State, offline, real-time — and browser security offline · xss

Cache layers, optimistic updates, IndexedDB, Service Workers, conflict resolution — then XSS, CSP, CSRF, cookies, tokens, and the npm supply chain.

Build: offline sync that loses no writes, plus working exploits on your own app.

Stage 4 · Months 10–12 · AI

Be the engineer who builds AI products, not the person who writes prompts. Same standard of proof as the browser months.

Month 10 · 19 Apr – 16 May 2027

Neural nets, built by hand backprop

The chain rule as code, tensors, attention, the training loop — typed by you, broken by you, fixed by you. Python becomes a real second language here.

Build: an autograd engine (~150 lines), then a small GPT you train yourself.

Month 11 · 17 May – 13 Jun 2027

LLM systems and the interfaces on top agents · evals

Tool calling from first principles, when a workflow beats an agent, retrieval done properly, evals that fail a deploy, cost budgets — and streaming interfaces done right.

Build: an agent from raw calls, a streaming chat UI, evals in CI, an MCP server.

Month 12 · 14 Jun – 30 Jul 2027 · final judge

Zero to one, alone, on a deadline ship it

A real problem where the interface is the hard part. Four weeks, fixed date, flexible scope. Then interview week, judged from outside.

Ship: a live AI product used by someone who is not you.
