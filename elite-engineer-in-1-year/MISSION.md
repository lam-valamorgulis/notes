# Mission: Elite Engineer in 1 Year — front-end to the metal, then AI

## Why
Become the engineer a founder like Steve Jobs or Elon Musk would actually hire and keep: someone who
**builds the interface from first principles, ships it to real users, and owns it when it breaks** —
and who can build the AI systems behind it too. Today I work at framework level: I use tools other
people built. In twelve months I want to be at machine level for the front end (engine, rendering,
framework, build, network) and genuinely capable in AI engineering. Target date: **August 2027**.

## Success looks like
- I have **rebuilt from a blank page**: a programming language interpreter, a layout engine, a React
  (fibers, hooks, scheduler), a bundler with hot module replacement, an HTTP server on a raw socket,
  an autograd engine, a small GPT, and an agent with no framework.
- I can explain **what a browser tab is** — processes, threads, the rendering pipeline — and trace any
  CSS or state change through every stage it touches.
- I can pass a **senior / staff front-end interview**: front-end system design, timed live coding, a
  deep-dive defence of my own work, and a code review with severity ratings.
- I can run a **performance campaign with field data** and prove the improvement for real users.
- I build **accessible interfaces to spec**, keyboard and screen-reader correct, because that is
  correctness and not decoration.
- I can build an **AI product**: agent loop from raw API calls, evaluations that gate deploys, cost
  and latency budgets, and a streaming interface that cancels cleanly.
- I have **shipped software to real users every month** — a public URL, someone other than me using
  it, and me on the hook when it breaks.
- I can **explain any of it in plain English in three minutes**, out loud, to a non-engineer.
- I have **published one public write-up per month**. Twelve artefacts that prove the year happened.

## Constraints
- **8 hours per day, 6 days a week.** Day 7 is review, publish, and rest. About 2,300 hours.
- **Stack fixed for the whole year: TypeScript (primary) + Python (secondary).** TypeScript for the
  browser and framework work, Python for the AI work. No switching languages mid-year.
- Evidence-only progress. Every month ends with a pass/fail gate. Feelings do not count.
- **Field data beats lab data.** No performance claim this year rests on a Lighthouse score.

## Out of scope
- **Database internals.** No storage engine, no write-ahead log this year. I read query plans when
  work needs it; I do not build the engine.
- **Distributed consensus.** I read the Raft paper. I do not implement Raft. Replaced by the parts a
  front-end engineer actually meets: retries, idempotency, offline sync, conflict resolution.
- **Server operations at fleet scale.** I monitor what I ship. I do not run infrastructure.
- **A third language.** No Go, Rust, C++ or Java. The small amount of C I read is for understanding.
- **Training or fine-tuning large models.** I build a small one by hand to understand it. Production
  AI work here is systems and interface work.
- **Mobile development** (that is the separate Flutter course) and **management** (the separate
  Engineering Manager course).
- **Certification collecting.** The proof is running software and a live defence.
