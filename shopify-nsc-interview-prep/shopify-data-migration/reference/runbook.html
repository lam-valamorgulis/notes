The Cutover Runbook

A printable checklist for the day it goes live. Every step has a name against it and a way to verify it. Nothing here is a judgement call — the judgement happened weeks earlier.

The rule this page enforces: the cutover hour should move minutes of data, not months. If a step below can be done a week early, do it a week early.

Do not skip the value checks in this phase Counts pass even when every historical order carries today's prices. If you only reconcile counts here, you will discover the money bug after go-live, when the client's accountant finds it.

The ★ rows are the ones that catch silent bugs. Counts alone would pass even if every historical order carried today's prices. This report shape is engineering practice, not a documented Shopify process.
