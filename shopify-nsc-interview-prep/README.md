## How we work
Say **"start day 1"** to begin, **"next"** to advance, **"go deeper on X"** for more detail,
or **"mock me"** any time. When you get the real job description, paste it and I re-target the
whole week to the client's actual stack.

**Keeping the Map current (rule for every session):** Whenever we add, rename, or remove
content in a session (a new lesson, kata, or reference), I update `index.html` in the same
session — I add the file to the right chapter list with a one-line description, weave it into
the "big picture" story so the narrative still connects, add the "← The Map" breadcrumb to any
new page, and check that no link is broken and no file is left unlinked. Keeping the Map in
sync is part of "done", the same way passing tests is part of done for code.
