Reference · Glossary

Glossary

Every key term in this sub-course, in one plain sentence. If you cannot define a word in one line, look it up here first.

How to use this: before the interview, cover the definition and say each term out loud from the name alone. The words in bold are the ones an interviewer will actually use.

The domain

TermPlain definition
OmnichannelJoining the online store and the physical shops so the customer sees one shop, not two.
Unified commerceA stricter omnichannel: all channels read from one shared, real-time data layer instead of separate systems synced in batches.
Find in StoreProduct-page feature showing which nearby shops have the item in stock, right now.
Store LocatorA map/list of stores with address, hours, phone, and stock status.
Click & Collect / BOPISBuy Online, Pick up In Store. The customer buys online and collects at a chosen shop.
Ship from StoreAn online order fulfilled (packed and shipped) from a physical shop instead of a warehouse.
SKUStock Keeping Unit — a product's unique stock code (e.g. a specific shoe in size 42, red).
POSPoint of Sale — the till/checkout system in the shop that records what is sold.
ERPEnterprise Resource Planning — the back-office system for stock, orders, and finance.
OMSOrder Management System — the part that decides which store fulfils each order and tracks it.
Last mileThe final delivery step from the fulfilling store to the customer's door, done by a courier.

Stock & availability

TermPlain definition
On-handThe raw count the store system thinks is physically present. Not the same as what you can safely sell.
Available / ATPAvailable-to-Promise — what you can safely sell after removing reserved units and a safety buffer. In Shopify this is the available state.
ReservedUnits held for an order that is not yet picked up. Must have an expiry so an abandoned order releases them.
CommittedShopify's state for units promised to a placed order that is not yet fulfilled.
Safety stock / bufferA cushion held back because the count is not fully trusted. Maps to Shopify's safety_stock state.
ThresholdA floor (per store, per SKU) below which you show "not available here" even if the raw count is 1 or 2.
Feed age / stalenessHow long ago the source measured this stock reading. Older = less trustworthy.
TTLTime To Live — how long a reservation is held before it automatically expires and releases the stock.

Ingestion & reliability

TermPlain definition
Push / pull / fileThe three ways stock arrives: push (the source calls your webhook), pull (you poll their API), file (a batch CSV/JSONL drop).
Delta vs full feedA delta feed sends only what changed (absent = unchanged). A full snapshot lists everything (absent = sold out = 0). You must know which.
NormaliseConvert each source's product code, store code, and units into your one canonical shape before storing.
UpsertInsert the row if new, or update it if it exists — in one statement, keyed on (location_id, sku).
IdempotencyApplying the same event twice has the same effect as once. Achieved by deduping on a source event id.
Staleness guardRejecting a reading older than the one you already have, so out-of-order events can't move stock backwards. Not the same as idempotency.
ReconciliationA scheduled re-read of a source's full stock to repair anything the event stream missed. Needs a full-snapshot capability.
Quarantine / dead-letterWhere a row that cannot be mapped or parsed goes, with an alert — instead of being silently dropped.
HMACA signature over the message using a shared secret, so you can verify a push feed (or Shopify webhook) is genuine and unaltered.
WebhookAn HTTP call a system makes to your endpoint when something happens, so you don't have to poll for it.
QueueA buffer between fast producers and slower consumers. Absorbs bursts and lets workers process at a safe rate.
BackpressureLetting consumers pull only as fast as they can handle, so a spike upstream never overwhelms the database.
Geospatial queryA "find the nearest stores to this location" search, using latitude/longitude and a distance index.
Fairness allocationSpreading Ship-from-Store orders across stores by stock, distance, and load, so no single store is overloaded.
You've got it when… you can cover the right column and define every bold term in one plain sentence, and you know the three pairs people confuse: on-hand vs available, idempotency vs staleness guard, and delta vs full feed.
