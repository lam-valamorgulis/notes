Platform — the model

QA
Where does a quantity live?InventoryLevel — a variant's inventory item at one location
What is actually sellable?The variant. A product is a display grouping
Max option axes? Max variants per product?3 axes · 2,048 variants
available vs on_hand?They differ by committed — sold but not shipped
Can one order have two shipments?Yes — one FulfillmentOrder per location
What creates a Location without you asking?A FulfillmentService
Missing InventoryLevel means?Absence, not zero. You cannot write to it
Why does tracked: false matter?No meaningful quantity; writes do nothing useful

Platform — custom data and checkout

QA
Metafield with no definition?Stored, readable by API, not editable, validated or filterable
Metafield or metaobject?Adjective vs noun. Several fields together, or shared → metaobject
Function input query metafield limit?10,000 bytes, then null
TOML creates which metaobject ownership?App-owned only. Merchant-owned needs GraphQL
Checkout UI on the payment step needs?Plus
Thank you / Order status extensions need?Any plan except Starter
Do Functions need Plus?No — any plan except Starter
Can a Function call your server?No. No network access, no retry, no URL
Two dated checkout cut-offs?Script tags on Thank you/Order status: 28 Aug 2025 Plus, 26 Aug 2026 non-Plus. React components: blocked from updating after 1 Oct 2026
What blocks Function APIs?A store still using checkout.liquid customisations

Sync

QA
Granularity of ownership?Per field. It splits inside one product
Who owns quantity in an ERP sync?Usually Shopify — that is where sales happen
Why absolute, not delta?Replay becomes free. A retry of a delta is a bug
Does "absolute" mean partial is fine?No — it must also be complete, or you delete the rest
How do you detect a deletion?You cannot from an absence. Needs a tombstone
Delete or archive in Shopify?Archive. A delete destroys the id, handle and URL
What is a webhook?A trigger, not a source. Read the current value
Which header dedupes? Which correlates?Webhook-Id dedupes · Event-Id correlates
Webhook timeouts and retries?1 s connect, 5 s total · 8 retries over 4 h, then deletion
Does a 301 count as success?No. Any non-2XX is a failure
Watermark value?Highest updatedAt you actually saw, source's clock
What is wrong with "newest wins"?It compares clocks you do not own. Use ownership
How big is a 12,000-message backlog really?Only the last value per record and field. Collapse to ids and re-read
Empty queue after a long outage means?Possibly the subscription was deleted. A warning, not a success
Why is a count a bad correctness check?Missing-plus-duplicate, wrong prices and stale stock all pass
What does shadow ≠ Shopify mean?Somebody else wrote it. An ownership decision, not a bug
Zero differences — is that a pass?Only if you publish the denominator
Rate-limit scope in multi-tenant?Per app and store. One budget per store, shared across workers
How do you report fleet health?The worst store and the count outside tolerance. Never the mean

Apps and integration

QA
Custom vs public app, key difference?Custom: one store, no review, no Billing API
Which token for a background job?Offline. Online is tied to a person's session
Token prefixes?shpat_ offline and online · shppa_ delegate
2027 deadline?Public apps must move off non-expiring offline tokens by Jan 2027
HMAC over what, keyed with what?The raw body, keyed with the app's client secret
Privacy level 2 trigger?Name, address, phone or email
Three compliance webhook topics?customers/data_request · customers/redact · shop/redact
Redaction timing surprise?Ordered within 6 months → request withheld for 6 months
Four integration shapes?Catalogue in · event out · decision during · state both ways
Fail open or closed?Open on information, closed on a promise
Bulk import: what proves it worked?The downloaded results file. Not COMPLETED, not objectCount
Where does the file field go?Last in the multipart form
Never match on?Title or handle. Both change when content is edited
Pairwise or hub mapping?Hub — your id in the middle. n links, not n(n−1)/2
Match coverage — report it how?By row and weighted by units sold
Which mutations upsert by custom ID?productSet and customerSet. productUpdate does not create
A short CSV feed — apply it?No. Hold for a human. Three outcomes, not two
SFTP failure nobody catches?No file arriving at all. Alert on absence
