Catalogue and stock

Product a group for display. NOT sellable. │ title · description · productType · vendor · tags · handle │ options[] (max 3) · metafields │ └─ ProductVariant THE SELLABLE THING. max 2048 per product. │ price · compareAtPrice · sku · barcode · optionValues │ metafields │ └─ InventoryItem the stockable thing. 1:1 with the variant. │ tracked · requiresShipping · unitCost │ └─ InventoryLevel ONE PER LOCATION. the quantity lives here. │ quantities(names: [...]) │ └─ Location a real place. shops, warehouses, popups, dropshippers, and fulfillment services.

The quantity names

NameMeansWatch
availableCan be sold right nowThis is what Shopify sells
on_handPhysically there, including promisedUsually what an ERP means by "stock"
committedSold, not yet shippedon_hand − committed ≈ available
incomingOn its way hereNot sellable
reserved · damagedHeld backNot sellable
The rule Never write on_hand into available. The difference is exactly what is already sold.

Orders and fulfilment

Order the customer's request to buy ├─ LineItem what they chose │ title = HISTORICAL · product.title / variant.title = CURRENT │ original_price · original_line_price │ final_price · final_line_price ← use these │ line_level_discount_allocations │ └─ FulfillmentOrder work from ONE location. an order can have SEVERAL. │ deliveryMethod: shipping | pickup | local delivery | … ├─ FulfillmentOrderLineItem └─ Fulfillment an actual shipment, with tracking FulfillmentService ── a third-party warehouse.
