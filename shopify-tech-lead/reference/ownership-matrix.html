Ownership matrix

The single most valuable page in the Course. Fill it in with the client, field by field.

How to fill it in Ask one question per row, and it is not "what is the source of truth". It is: "if these two systems disagree tomorrow morning, which one would you believe?" Anyone can answer that. Store this file in the repo, reviewable in a diff — a decision made in a meeting evaporates.

The four patterns

CodePatternConflict possible?
→Owned upstream. External system decides, Shopify followsNo. Prefer this
←Owned downstream. Shopify decides, external followsNo. Prefer this
↔Shared, with a written ruleYes. Where bugs live
✕Excluded from the sync entirelyN/A. A valid and underused answer

The three questions this table exists to answer

1. Is that stock number SELLABLE stock, or everything on the shelf? 2. Does anyone edit product data DIRECTLY in Shopify? 3. What should happen when the other system is unreachable?
